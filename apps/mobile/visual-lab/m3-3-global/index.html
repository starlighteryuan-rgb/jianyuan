见渊 · M3.3 Global Visual Language

One system, two themes. Light is Warm Paper, Dark is Deep Amber. Same token roles, same geometry, different values — not two products and not an inverted copy.

Review board · design reference only. No runtime code changed. Bubble emergence timing 520 / 420 / 820 ms shown as static frames.

1 · Theme system — role values

Every role below exists in both themes with the same name. Light is a warm paper ground; Dark is a warm near-black ground, never neon and never black-gold luxury.

10 · Motion — awareness emergence, frozen timing as frames

Frozen: bubble ≈520 ms, content ≈420 ms, ripple ≈820 ms. A light gather, then the shape, then the text, then the ripple dissipating. No bounce, no loop, no pulse.

12 · Surface hierarchy — five levels, and when each appears

LevelTreatmentAppears when
0 · Nonecanvas only, separation by space + hairlinerecord at rest, day groups, thread
1 · Faint surfacesurface fill, no border, no shadowan opened record, a settled understanding
2 · Interactive surfacesurface fill + hairline borderthe write-in well, a pressed control
3 · Object surfacesurface + awareness edge, optional halo, one soft shadowawareness bubble / opened object
4 · Overlayelevated fill over scrima true modal or picker — used rarely

Card is not the default answer. Level 0 and 1 carry most of the product; level 3 is reserved for awareness, where the object genuinely is the point.
