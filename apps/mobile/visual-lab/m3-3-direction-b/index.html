见渊 · M3.3 Direction B — Spatial / Depth

内容不只是排在列表里，而像存在于一个有轻微深度的心理空间里。

这一版的组织原则是层级，不是排版。记录、觉察、理解、关系各自占据不同的深度层，含义由它处在哪一层承担。深度只用 tone、对比、极小 scale、位置和轻微叠压表达 —— 不靠堆阴影，不做 3D。

设计评审稿 · 未改动任何运行时 UI · 导航交互合同与 Awareness 520/420/820ms 保持不变

0 · Depth Grammar — 四层，克制

每一层都有固定的语义和固定的视觉表达方式。同一层在两个主题里是同一个角色，只是取值不同。

Layer语义视觉效果（不靠阴影）LightDark
base安静的底：只承载氛围，不放内容页面底色 + 极轻径向 tone#e9ece8#111413
rest长期存在、稳定的内容：后退较窄边距 + scale .965 + 较低对比文字#f1f3ef#171b19
active用户此刻正在阅读或操作的内容正常边距 + scale .985 + 正常对比#f8faf7#1e2321
emerge刚刚浮现、需要注意的内容最宽边距 + scale 1 + 最高对比 + 唯一一层允许一层柔和环境阴影#fcfefb#252b28

深度的差别主要来自 tone 亮度 + 对比度 + 边距/宽度 + 极小缩放 + 轻微叠压。阴影只在 emerge 这一层出现一次，用来把「刚浮出来的东西」和「稳定存在的东西」分开；其他层完全不用阴影。

1 · Record — 新记录近，旧记录沉回去

记录落在不同纵向层面：最新一条在最前，旧的逐层后退（更窄、更淡、更低）。日期是空间坐标不是 section header。标签是钉在平面边缘的 anchor 记号。正文永远可读，时间顺序不变。

不是列表 + 连线。内容节点按深度分布在空间里：离得近的在同一层，跨时间的更远、更小、更淡。连接线在节点之间真实存在，支持强的线是强调色。用户看到的是「某些距离被缩短」，不是「一个图被管理」。

8 · Direction A vs Direction B — 一眼看出差异

不重复贴整块板，只做对照。

Direction A · Editorial / Quiet Archive

composition页边索引栏 + 正文栏双栏；时间在左栏
surface几乎无 surface，用细规则线与留白分隔
hierarchy由字体层级与留白承担
rhythm条目 26px / 日期 40px 的阅读段落节奏
Awareness居中声明 + 同心 1px 圆环（halo）
Exploration编号索引 + 织线
emotional tone纸本、档案、书房；安静而书卷

Direction B · Spatial / Depth

composition纵向叠压的深度平面；内容处在不同层
surface用 tone 不同的平面表达层级；只有 emerge 层用一层柔和阴影
hierarchy由深度承担：远近、宽窄、对比、极小缩放
rhythm由平面叠压与位移形成的空间节奏
Awarenessghost 平面在背后，emerge 对象从深处进入前景
Exploration节点按深度分布，连接线用实际距离表达关系
emotional tone矿物、薄暮、心理空间；安静但有纵深

9 · Card 自检

画面平面数量是否必要
Record3 个平面（emerge/active/rest）必要：平面本身就是「新→旧」的深度表达，不是装饰容器
Awareness 主页1 个对象 + 3 个 ghost必要：ghost 表达「还在背景里」，对象表达「走近了」
Awareness 打开1 个前景对象 + 1 条 behind strip必要：前景/背景的对比就是这一版的核心命题
Understanding3 个叠压平面必要：叠压表达「一层层沉下去」的顺序
Exploration5 个节点（无容器卡片，按深度分布）节点是空间坐标点，不是列表行
Search1 个 emerge 结果 + 1 个 rest 背景表达搜索进入前景

结论：Direction B 使用平面（plane）表达深度，而不是用矩形卡片承载列表条目。平面之间的差别由 tone、宽窄、缩放、偏移和叠压承担；全板只有 emerge 层出现一次柔和阴影。不存在「一条内容 = 一张圆角 Card」的列表。
